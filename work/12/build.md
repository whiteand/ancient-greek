## Переклад

- `PŘÍDAVNÁ JMÉNA` / `ADJEKTIVA` → `Прикметники`.
- `Adjektiva II. a I. dekl.` → `Прикметники II та I відміни` (порядок II, потім I, як на скані; `dekl.` розгорнуто до `відміна`, як на решті сторінки).
- `trojvýchodná` / `dvojvýchodná` → `трьох закінчень` / `двох закінчень` (йдеться про кількість закінчень, не родів). `adj.` розгорнуто до `прикметники`. `stažená` → `стягнені`.
- `f.` → `жін.`, `M.` / `m.` → `чол.`, `n.` → `сер.`, `sg.` → `одн.`, `pl.` → `мн.`, `nom.` → `наз.`, `ak.` → `зн.`.
- `dle` / `podle` → `за`; `substantiv` → `іменників`; `po` → `після`; `jinak` → `інакше`.
- `maskulina a neutra se skloňují` → `чол. та сер. відмінюються`; `skloňuje se` (однина, про `εὔνους`) → `відмінюється`.
- `nom. + ak. pl. n. = εὔνοα` → `наз. + зн. мн. сер. = εὔνοα`.
- Глоси: `dobrý` добрий, `spravedlivý` справедливий, `zlatý` золотий, `stříbrný` срібний, `klidný` спокійний, `příznivý` прихильний (для `εὔνους`; чеське `příznivý` також буває «сприятливий»).
