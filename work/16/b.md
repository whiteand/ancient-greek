Примітки до таблиці:
- Рожевим виділені закінчення (у транскрипції `**…**`).

- У Gen./Dat./Ak. sg. під 3. os. два стовпчики: короткі форми (οὗ / οἷ / ἕ) і складені (ἑαυτοῦ…).

## Блок 4 — абзац під таблицею (про 3. os.)
Тип: абзац

Tvary **3.os.** jsou **zvratné**; místo nezvratných zájmen se užívá nedůrazného zájmena αὐτ**ός**, -**ή**, -**όν** a důrazného ἐκεῖνος, -η, -ο či οὗτος, αὕτη, τοῦτο (viz demonstrativa).

## Блок 5 — абзац про стягнені форми
Тип: абзац

Místo tvarů σεαυτ**όν**, ἑαυτ**όν** atd. se užívá též tvarů σαυτ**όν**, αὑτ**όν** atd.

## Блок 6 — приклад
Тип: абзац

**Příklad:** λέγω περὶ σοῦ *mluvím o tobě* [колір: cyan], ale λέγεις περὶ σαυτοῦ *mluvíš o sobě* [колір: cyan]. Přízvučné tvary nepřímých pádů v sg. se kladou po předložkách a při zdůraznění.

## Сумніви
- Блок 3, Nom.sg. 3. os.: на відбитку видно один довгий тире під 3. os.; у мн. там два стовпчики (`σφεῖς` | `–`). Чи друге тире злите з першим / комірка об’єднана — позначено `–(?)` у шостому стовпчику.
- Блок 3, Gen. `οὗ`, `οὑ`: дихання на парі то читається як rough, то як smooth; взято rough (`οὗ`, `οὑ` з grave на енклітиці). Можлива альтернатива — smooth.
- Блок 3, Dat. `οἷ`, `οἱ` і Ak. `ἕ`, `ἑ`: те саме щодо rough vs smooth; взято rough. На `οἱ` / `ἑ` — acute (не grave).
- Блок 3, Gen. закінчення `-ῆς` (ἐμαυτοῦ,-ῆς тощо): модель іноді «бачить» iota subscript під η; на збільшених кропах iota немає (лише circumflex) — записано `-ῆς` без iota.
- Блок 3, Ak.pl. `αὐτούς` (1./2. os. zvratné): переважно smooth (`αὐτ-`); один кроп 2. os. читався як rough `αὑτούς` — сумнів smooth vs rough.
- Блок 3, Ak.pl. `-ᾱ́ς`: macron + acute підтверджено; іноді опис плутає acute з circumflex.
- Блок 3, рожеві закінчення на коротких формах (`μου`, `μοι`, `με`, `οὗ`…): весь фон таблиці рожевуватий, точна межа stem/ending на енклітиках не завжди очевидна — позначено цілі короткі форми як `**…**`.
- Блок 3, коми: `ἐμοῦ, μου` / `ἐμοί, μοι` зі пробілом; `σοῦ,σου` без пробілу; `αὐτούς, -ᾱ́ς` зі пробілом після коми; `αὐτοῖς,-αῖς` і `-ῆς` без пробілу — як на відбитку.
- Блок 3, Ak. sg. 1./2. os. zvratné: лише `-όν,-ήν` (без нейтрального `-ό`); `-ό` лише в 3. os. (`ἑαυτόν,-ήν,-ό`).
- Блок 4: чи рожеві закінчення в `αὐτός, -ή, -όν` (і чи `-ή` з acute) — ймовірно так; у `ἐκεῖνος, -η, -ο` закінчення без явного рожевого.
- Блок 4: `οὗτος` — rough (як αὕτη); один опис давав smooth.
- Блок 4/6: `3.os.` / `zvratné` / `Příklad` — жирні; глоси прикладу — cyan + курсив (як *já* тощо).
- Блок 6: `σαυτοῦ` (не `σεαυτοῦ`) у прикладі — підтверджено.
