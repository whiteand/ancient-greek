# Скан 11 — збірка

## Додано

- `src/components/DualDeclensionTable.vue` — двоїна I–III відмін. У кожної відміни три колонки: рожеве закінчення (разом із дефісом, без шапки), артикль (`text-right`), зразок. Шапка курсивом (`I відміна`, `II відміна`, `III відміна`) стоїть над парою «артикль + зразок», не над закінченням. Усередині словоформ рожевого немає. У III відміні дві форми через кому: `φύλακε, γένει` і `φυλάκοιν, γενοῖν`.
- Підключено в `src/components/NounsExplanation.vue` після голосних основ: підзаголовок, абзац, таблиця.
- `SectionSubheader` `id="dual"` — у `TableOfContents.vue` як дочірній пункт «Іменники».

Нижче `27rem` відміни стовпчиком; у III відміні друга форма переноситься під першу, щоб рядок вмістився на 320px. Від `27rem` обидві форми III відміни в один рядок, відміни ще стовпчиком. Від `md` (48rem) усі три відміни в один ряд. Сітка `w-fit`, по центру, не на всю ширину.

Тонка рамка навколо абзаца й таблиці на скані — край картки; на сторінці блок іде звичайним підрозділом іменників.

## Переклад

- `Duál` → `Двоїна` (і підзаголовок для змісту, і жирне перше слово речення, як на скані).
- `číslo dvojné` → `двоїне число`.
- `právě dvě entity` → `саме дві сутності`.
- `užívá se v attičtině, ale ne zcela důsledně` → `вживається в аттичному діалекті, але не цілком послідовно`.
- `I. dekl.` / `II. dekl.` / `III. dekl.` → `I відміна` / `II відміна` / `III відміна` (повне слово, як у решті сторінки).
- `Nom., ak., vok.` → `Наз., Зн., Кл.`; `Gen., dat.` → `Род., Дав.` через `CASE_SHORTEN_NAME`, у порядку скану (називний, знахідний, кличний — не звичайний порядок відмінків). Числа `одн.`/`мн.` немає: уся таблиця є двоїною, і на скані число в рядках не підписане.

## Сумнівні місця (для рев'ю)
