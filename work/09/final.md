# Скан 09 — транскрипція

## Блок 1 — заголовок (верхній рядок)
Тип: заголовок

***f) na sykavku*** -σ [колір: блакитний, лише дефіс і σ; двокрапка чорна]: *neutra*  *mask. (jen vlastní jména)*

«f) na sykavku» — жирний курсив. *neutra* і *mask. (jen vlastní jména)* — курсив, не жирний. Обидва підписи надруковані один раз, на цьому ж рядку: *neutra* одразу після двокрапки (над стовпцями γένος), *mask. (jen vlastní jména)* правіше (над Σωκράτης і Περικλῆς). У таблиці нижче вони повторені як шапка стовпців.

## Блок 2 — таблиця (γένος, Σωκράτης, Περικλῆς)
Тип: таблиця

Артиклів немає. «pl.» надруковано лише в рядку Nom., окремо між формою однини і формою множини.

| | *neutra* | | | *mask. (jen vlastní jména)* | |
|---|---|---|---|---|---|
| Nom. sg. | γέν**ος** | pl. | γέν**η** | Σωκράτ**ης** | Περικλ**ῆς** |
| Gen. | γέν**ους** | | γεν**ῶν** | Σωκράτ**ους** | Περικλ**έους** |
| Dat. | γέν**ει** | | γέν**εσι** | Σωκράτ**ει** | Περικλ**εῖ** |
| Ak. | γέν**ος** | | γέν**η** | Σωκράτ**η** **(-ην)** | Περικλ**έᾱ** |
| Vok. | | = nom. | | Σώκρατ**ες** | Περίκλ**εις** |

Примітки до таблиці:

- «= nom.» у рядку Vok. стоїть один раз у проміжку між стовпцями sg. і pl. (починається під правим краєм sg., закінчується перед γένη) і стосується обох чисел *neutra*.
- Рожевим надруковано закінчення, як у `**…**`. **(-ην)** рожеве цілком: дужки, дефіс і ην. У Περικλ**ῆς**, Περικλ**έους**, Περικλ**εῖ**, Περικλ**έᾱ** наголошена літера закінчення теж рожева.
- Ak. Περικλ**έᾱ** — α з макроном; гострий наголос на ε. Бревісів і йоти підписаної на сторінці немає.
- Vok. Σώκρατ**ες** — циркумфлекс на ω; Περίκλ**εις** — гострий наголос на ι. Gen. pl. γεν**ῶν** — циркумфлекс на ω, ε без наголосу.

## Блок 3 — рамка праворуч
Тип: примітка

Рамка [колір: блакитна лінія], тло жовте. Жирним лише два місця: «Většina pád. koncovek» і «stažením».

**Většina pád. koncovek** vznikla **stažením**, takže původní kmen již není patrný (γενοσ- / γενεσ-, Σωκρατεσ-, Περικλεεσ-): např. gen. pl. γενεσων > γενῶν.
Kmen není zřetelný ani u samohl. kmenů.

Грецькі основи в дужках і γενεσων — без наголосів; γενῶν — з циркумфлексом. Переноси рядків у рамці (верстка, не окремі абзаци): «Většina pád. koncovek vznikla / stažením, takže původní kmen již / není patrný (γενοσ- / γενεσ-, / Σωκρατεσ-, Περικλεεσ-): např. / gen. pl. γενεσων > γενῶν. / Kmen není zřetelný ani u samohl. / kmenů.»
