## Переклад

- `Adjektiva III. deklinace` → `Прикметники III відміни`.
- `trojvýchodná` / `dvojvýchodná` / `jednovýchodná` → `трьох` / `двох` / `одного закінчень` (як на скані 12). `adj.` розгорнуто до `прикметники`.
- `kmeny zakončené na prostou dentálu` → `основи, що закінчуються на простий зубний` (простий зубний на відміну від `-ντ`).
- `na nosovku` → `на носовий`, `na sykavku` → `на сибілянт` (як у таблицях іменників). Перелік a)–e) → а) б) в) г) д).
- `t-kmenů` / `n-kmeny` → `<em>t</em>`-основи / `<em>n</em>`-основи: латинська літера блакитна й курсивна, «основи» чорні.
- `participium pf. akt.` → `дієприкметник перф. акт.`; `part. préz. akt.` → `дієприкм. през. акт.`; `part. aor. pas.` → `дієприкм. аор. пас.`
- `m.` / `f.` / `n.` → `чол.` / `жін.` / `сер.`. `m. a n. se skloňuje` → `чол. та сер. відмінюються`.
- Глоси: `chudý` бідний, `bezdětný` бездітний, `celý, všechen` цілий, весь, `půvabný` принадний, `černý` чорний. `rád` для ἑκών передано як `охочий` (чеське `rád` тут «з власної волі», не «радий»).
- У нижній таблиці зн. мн. підписано `Зн. мн.`, бо на скані саме там стоїть `Ak. pl.`; у таблиці πᾶς зн. мн. лишається `Зн.`
