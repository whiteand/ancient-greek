# Скан 10 — транскрипція

SAMOHLÁSKOVÉ KMENY

## Блок 2 — таблиця парадигм на всю ширину
Тип: таблиця

Блакитні заголовки основ, зліва направо: `-ι`, `-υ`, `-ῡ`, `-ευ`, `-ου`, `-αυ` [колір: блакитний]. Макрон є лише в `-ῡ` (рівна риска над υ, без акценту). На `-ι` і `-υ` немає ні макрона, ні бревіса. Мітка `-υ` одна: вона стоїть у проміжку між колонками πῆχυς і ἄστυ (спільна для обох коротких υ-основ), а не повторена над ἄστυ.

Артиклі лише в рядку Nom. sg., у власному стовпці ліворуч від слова. Між Vok. і Nom. pl. проведена горизонтальна лінія. Вокатива множини немає.

У заголовку таблиці порожня клітинка над ἄστυ — це та сама єдина мітка `-υ` (вона не надрукована вдруге).

Рожеві (закінчення) — те, що в `**…**`. У колонках βοῦς і ναῦς рожевого немає: усі літери чорні. Вокатив ἰχθύ теж увесь чорний.

Риска у вокативі ναῦς довша за дефіс у заголовках основ (приблизно вдвічі). У Nom. pl. βασιλεύς після коми є пробіл, кома чорна, дефіс рожевий: `βασιλ**ῆς**, **-εῖς**. В Ak. множини пробілу після коми немає, і кома, і дефіс рожеві: `βασιλ**έᾱς,-εῖς**. Над α в βασιλέᾱ / βασιλέᾱς — макрон (рівна риска), акут стоїть на ε.

## Блок 4 — рамка справа під таблицею
Тип: таблиця

Рамка з блакитною обводкою. Заголовок усередині рамки: Kmeny na -ω [колір: блакитний] a -οι [колір: блакитний].

Три колонки прикладів (артикуль у Nom. — у власному стовпці). Окремого підпису pl. над третьою колонкою немає.

| | | | | | | |
| --- | --- | --- | --- | --- | --- | --- |
| Nom. | ἡ | πειθ**ώ** | ὁ | ἥρω**ς** | οἱ | ἥρω**ες** |
| Gen. | | πειθ**οῦς** | | ἥρω**ος** | | ἡρώ**ων** |
| Dat. | | πειθ**οῖ** | | ἥρω**ϊ** | | ἥρω**σι** |
| Ak. | | = nom. | | ἥρω**α** | | ἥρω**ας** |
| Vok. | | πειθ**οῖ** | | = nom. | | = nom. |

У ἡρώων акут на першій ω (чорна), придих на η без акценту; рожеві лише кінцеві ων. У ἥρωϊ на ι лише трема (дві рожеві крапки), без акценту на ι; акут і дасія на η. У πειθώ / πειθοῦς / πειθοῖ циркумфлекс стоїть на рожевому закінченні (ώ, οῦς, οῖ). «= nom.» — малими літерами, з пробілами навколо знака рівності і з крапкою.

## Сумніви

- Блок 2, Nom. sg. перед πόλις: `η(?)` — над η немає знака придиху (пікселі тла; на відміну від чіткої дасії в ἡ ναῦς). Альтернатива: ἡ, якщо придих втрачено при друці/скані.
- Блок 2, колонка ἄστυ: `ἄ(?)` — пара «придих + акут» на α є в усіх формах колонки; гачок придиху читається як псіле (ἄ), але на збільшенні напрямок легко сплутати з дасією (ἅ).
- Блок 2, ἰχθῦς (Nom. sg.) та ἰχθῦν (Ak. sg.): на υ саме циркумфлекс (широка арка з двома ніжками), та сама форма знака, що й в Ak. pl. ἰχθῦς. В інших відмінках цієї колонки (Gen., Dat., Vok., Nom. pl., Gen. pl., Dat. pl.) на υ акут. Читання знака певне; форма незвична відносно словникового ἰχθύς / ἰχθύν.
- Блок 2, βοῦς і ναῦς: на дифтонгу надруковано лише циркумфлекс, окремого придиху біля υ не видно (пор. чисту арку з Nom. sg. βοῦς, ναῦς).
- Блок 2, Vok. ναῦς: риска довша за дефіс заголовків `-ι` тощо (≈2×); передано як `–`. Альтернатива — довге тире `—`.
- Блок 2, Nom. pl. βασιλεύς: кома чорна і після неї пробіл (`βασιλ**ῆς**, **-εῖς**`). В Ak. pl. коми без пробілу і кома рожева (`βασιλ**έᾱς,-εῖς**`).
- Блок 3, Ζεύς: на υ акут (вузький діагональний штрих). Поруч у тому самому рядку Ζεῦ має циркумфлекс (широка арка). Διός, Διΐ, Δία — з акутом; у Διΐ ще й трема на ι.
- Блок 3, ᾿(?)Αργώ: перед великою Α є гачок на зразок коми (схожий на псіле ᾿). Дасія ῾ на цьому розділенні не відділяється впевнено. Циркумфлекс на ω в Αργώ і в Σαπφώ певний; після Σαπφώ стоїть крапка.
