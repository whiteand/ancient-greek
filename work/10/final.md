# Скан 10 — транскрипція

Тип: заголовок

SAMOHLÁSKOVÉ KMENY

## Блок 2 — таблиця парадигм на всю ширину
Тип: таблиця

Мітки основ зверху, зліва направо, [колір: блакитний]: `-ι`, `-υ`, `-ῡ`, `-ευ`, `-ου`, `-αυ`. Макрон є лише в `-ῡ` (рівна риска над υ, без акценту). На `-ι` і `-υ` немає ні макрона, ні бревіса. Мітка `-υ` одна: вона стоїть у проміжку між колонками πῆχυς і ἄστυ (спільна для обох коротких υ-основ). У сітці нижче її поставлено в колонку πῆχυς; клітинка шапки над ἄστυ порожня.

Артиклі лише в рядку Nom. sg., у власному стовпці ліворуч від слова. Між Vok. і Nom. pl. горизонтальна лінія. Вокатива множини немає.

| Nom. sg. | η | πόλ**ις** | ὁ | πῆχ**υς** | τὸ | ἄστ**υ** | ὁ | ἰχθῦ**ς** | ὁ | βασιλ**εύς** | ὁ | βοῦς | ἡ | ναῦς |
| Gen. | | πόλ**εως** | | πήχ**εως** | | ἄστ**εως** | | ἰχθύ**ος** | | βασιλ**έως** | | βοός | | νεώς |

Рожеві (закінчення) — те, що в `**…**`. Колонки βοῦς і ναῦς цілком чорні. Вокатив ἰχθύ і (βοῦ) теж цілком чорні, разом із дужками.

Артикль перед πόλις — η без придиху. Інші `ὁ`, `ἡ` — густий придих без гравіса; `τὸ` — з гравісом. У колонці ἄστυ на α скрізь псіле й гострий (`ἄ`).

Наголос у колонці πῆχυς: циркумфлекс у Nom./Ak./Vok. sg. (`πῆ`), гострий у решті (`πή`). У колонці ἰχθύς циркумфлекс на υ в Nom. sg. (`ἰχθῦς`), Ak. sg. (`ἰχθῦν`) і Ak. pl. (`ἰχθῦς`); у решті форм цієї колонки на υ гострий. У `ἰχθύϊ` над ι лише трема.

У Nom. pl. βασιλεύς після коми є пробіл, кома чорна, дефіс рожевий: `βασιλ**ῆς**, **-εῖς**`. В Ak. pl. пробілу немає, кома й дефіс рожеві: `βασιλ**έᾱς,-εῖς**`. Над α в `έᾱ` / `έᾱς` — макрон (рівна риска, без наголосу); гострий наголос на ε.

У Vok. ναῦς риска `–` (довша за дефіс шапки `-ι`, близько ширини однієї літери). У βοῦς і ναῦς на дифтонгу надруковано лише циркумфлекс, окремого придиху біля υ немає. Gen. νεώς — гострий на ω, не циркумфлекс.

## Блок 3 — маркований список зліва під таблицею
Тип: список

Три пункти. Другий і третій переносяться на наступний рядок без нової крапки.

• Subst. na -ις [колір: блакитний] bývají feminina, na -εύς [коліρ: блакитний] mask.

• K jednoslab. diftongickým kmenům na -αυ [колір: блакитний], -ου [колір: блакитний]
patří i eu-kmeny: Ζεύς, Διός, Διΐ, Δία, Ζεῦ.

(*eu* в eu-kmeny — курсив, [колір: блакитний]; «kmeny» звичайним чорним)

• Kmeny na -ω [колір: блакитний] a -οι [коліρ: блакитний] jsou většinou ženská jména
s přízvukem na posl. slabice: ᾿Αργῶ, Σαπφώ.

Грецькі форми в пунктах чорні. У Διΐ над другою ι трема й гострий; у Διός, Δία, Ζεύς — гострий; у Ζεῦ — циркумфлекс. Перед Αργῶ окреме псіле `᾿` (не на самій альфі); на ω циркумфлекс. У Σαπφώ на ω гострий. Після Σαπφώ крапка.

## Блок 4 — рамка справа під таблицею
Тип: таблиця

Рамка з блакитною обводкою. Заголовок усередині рамки, жирний: Kmeny na -ω [колір: блакитний] a -οι [колір: блакитний].

Окремого підпису pl. немає. Артиклі лише в Nom., у власному стовпці.

| | | | | | | |
| --- | --- | --- | --- | --- | --- | --- |
| Nom. | ἡ | πειθ**ώ** | ὁ | ἥρω**ς** | οἱ | ἥρω**ες** |
| Gen. | | πειθ**οῦς** | | ἥρω**ος** | | ἡρώ**ων** |
| Dat. | | πειθ**οῖ** | | ἥρω**ϊ** | | ἥρω**σι** |
| Ak. | | = nom. | | ἥρω**α** | | ἥρω**ας** |
| Vok. | | πειθ**οῖ** | | = nom. | | = nom. |

Рожеві закінчення — у `**…**`. У Nom. πειθώ над рожевою ω гострий. У Gen. πειθοῦς і Dat./Vok. πειθοῖ — циркумфлекс на рожевому закінченні. У ἥρωϊ над ι лише трема. У ἡρώων гострий на першій ω (чорна), придих на η без акценту; рожеві лише ων. `ἡ`, `ὁ` — густий придих без гравіса; `οἱ` — густий придих без наголосу; `ἥ` — густий придих і гострий. «= nom.» — з пробілом після знака рівності і з крапкою; лівий край `=` збігається з лівим краєм слова в колонці.
